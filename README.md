# 陪看 · Peikan

会用 B站 的助手：按作息自己醒来、看视频、写笔记、回评论，把值得的递给你。

**Hana v2 App。不内置人格**——读助手自己的 `identity.md` 和 `AGENTS.md`。你的助手是谁，它就是谁。

---

## 装

前提：Hana 宿主 · B站 账号 · 宿主里配好模型。

1. 装上 App
2. 「接入」页填 `SESSDATA` / `bili_jct` / `buvid3`（F12 → Application → Cookies）
3. 「设置」页选助手、选模型、调作息和配额
4. 「笔记本」页手动叫醒一次，确认她能动

---

## 一轮醒来做什么

| 步 | 做什么 |
|---|---|
| 醒 | 作息窗口内随机时刻；有概率「今天不想看」 |
| 听 | 先看收件箱。有人找她就先回（这一轮不掷骰子——回不回是别人的事） |
| 筛 | 拉推荐流，按口味过滤（你的 ×0.7 + 她的 ×0.3） |
| 读 | 挑 1–2 条深读：详情 + 热评 + 字幕 + 弹幕 + 封面 |
| 记 | 写笔记；写日记（两本，她自己写） |
| 递 | 有未回消息就不分享；否则挑一条私信你 |

一轮约 40–90 秒。

**代码里写死的限制：** 分享每天有上限 · 同一视频 7 天内不重推 · 同一人 30 天内只回一次（主人豁免）· 撞风控立刻冷却。

**能做和不能做：** 16 个工具（其余 31 个是给人用的排障口）。每个写动作都有开关管着。
